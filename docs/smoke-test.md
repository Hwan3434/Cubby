# Smoke Test Checklist

실기기에서 한 번씩 돌려볼 시나리오. 디자인 적용 후에도 동일한 항목으로 회귀 검증.

## 사전 준비

- [ ] Flutter SDK 3.41+ 설치
- [ ] `flutter config --enable-swift-package-manager` (iOS 작업 시)
- [ ] `flutter pub get`
- [ ] Android 기기/에뮬레이터 (API 30+ 권장 — 삭제 다이얼로그 검증용)
- [ ] iOS 기기 (Simulator는 카메라 없음)

## 1. 권한 흐름

### 1.1 시작 게이트
- [ ] 첫 실행 시 즉시 사진 권한 다이얼로그 표시 (게이트 화면)
- [ ] **거부 → "권한 필요" 다이얼로그 → "종료" → 앱 종료**
- [ ] iOS Limited 선택 → 앨범 화면으로 진입 (limited 배너 보임)
- [ ] 허용 → 앨범 화면으로 진입

### 1.2 앨범 화면 권한 분기 (게이트 통과 후 외부에서 권한 회수된 케이스)
- [ ] AlbumsScreen에서 권한 거부 상태 → "설정 열기" 버튼 노출, 클릭 시 OS 설정 페이지 이동
- [ ] limited 배너의 "더 추가" 버튼 → 사진 선택 모달 표시 → 닫으면 목록 갱신

## 2. 앨범 목록 (F1)

- [ ] 시스템 앨범이 모두 표시됨 (카운트, 생성일이 있으면 표시)
- [ ] Pull-to-refresh로 새로고침 동작
- [ ] FAB → 앨범 생성 다이얼로그 표시

## 3. 앨범 생성 (F2)

- [ ] 빈 이름 입력 → 아무 일도 없음 (다이얼로그 닫힘)
- [ ] 이미 존재하는 이름 입력 → 그 앨범이 그대로 보임 (중복 생성 안 됨)
- [ ] iOS 새 이름 입력 → 즉시 빈 앨범 생성, 목록에 추가, `createdAt` 저장 확인
- [ ] Android 새 이름 입력 → 안내 스낵바 표시, 첫 사진 촬영 후 앨범 등장 확인

## 4. 사진 그리드 (F4)

- [ ] 앨범 탭 → 그리드 표시, 촬영일 내림차순
- [ ] 80장 초과 시 스크롤하면 추가 페이지 로드
- [ ] 영상 항목엔 비디오 아이콘 오버레이

## 4.5 사진 상세 페이저

- [ ] 사진(선택 모드 X) 탭 → 상세 화면으로 이동, 해당 사진이 보임
- [ ] 좌우 스와이프 → 다음/이전 사진으로 페이지 이동
- [ ] AppBar 타이틀에 `현재 / 전체` 카운트 표시
- [ ] 핀치 줌-인/아웃 정상 동작
- [ ] 영상 항목은 썸네일 + 재생 아이콘 오버레이로 표시 (재생은 미지원)
- [ ] 손상/접근불가 자산은 깨진 이미지 아이콘으로 fallback

## 5. 카메라 — 사진 (F5)

- [ ] 카메라 버튼 → 프리뷰 표시, 모드 토글(사진/영상) 보임
- [ ] 사진 셔터 탭 → 진행 인디케이터 → 자동 pop
- [ ] 돌아오면 새 사진이 그리드 첫 위치에 노출
- [ ] 시스템 갤러리 앱 열어서도 동일 앨범에 사진 노출 확인 (F8)

## 6. 카메라 — 영상

- [ ] 영상 모드로 토글 → 셔터가 빨간 원으로 변경
- [ ] 영상 셔터 탭 → REC 칩 표시, 셔터 안쪽이 사각형으로 변형
- [ ] 다시 셔터 탭 → 저장 후 자동 pop
- [ ] 그리드에 영상 노출, 비디오 아이콘 표시
- [ ] 시스템 갤러리에서 재생 가능 (F8)

## 7. 삭제 (F6)

- [ ] 사진 길게 누르기 → 선택 모드 진입, 체크 표시
- [ ] 추가 항목 탭으로 다중 선택
- [ ] 삭제 버튼 탭 → OS 시스템 다이얼로그 표시
- [ ] "삭제" 누름 → 그리드에서 즉시 사라짐
- [ ] "취소" 누름 → 선택은 남고 그리드 변화 없음
- [ ] 시스템 갤러리에서도 사라짐 확인

## 7.5 공유 (Share Sheet)

- [ ] 선택 모드에서 공유 아이콘 노출
- [ ] 공유 탭 → OS 공유 시트 표시 (선택한 사진/영상 첨부됨)
- [ ] 카카오톡/메시지/메일 등 외부 앱 선택 → 첨부물이 정상 전달
- [ ] iCloud 전용 자산 포함 시 다운로드 후 공유 (시간 소요 가능)
- [ ] 공유 시트 취소 시 선택 상태 유지, 아무 변화 없음

## 8. 촬영일 표시 (F7)

- [ ] 사진 상세/메타 표시되는 위치(디자인 적용 후)에서 EXIF/시스템 촬영일이 보임 — 현재 placeholder는 미적용

## 9. 알려진 제약

- 앨범 이름 변경 — MVP 비요구사항
- 사진 편집 — 비요구사항
- iCloud 자산 다운로드 진행 — 미처리 (대용량 원본은 첫 접근 시 잠깐 멈출 수 있음)
- HEIC 직접 렌더 — 썸네일 API 사용으로 회피, 원본 표시 화면 들어가면 별도 처리 필요

## 10. 회귀 회피용 빠른 검사

- [ ] `flutter analyze` — issue 0
- [ ] `flutter test` — 5/5 pass
- [ ] 권한 거부 분기 위젯 테스트 통과
