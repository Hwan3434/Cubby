# Cubby

Personal camera/album Flutter app.

See [docs/design.md](docs/design.md) for the design document.

## Getting Started

```bash
flutter config --enable-swift-package-manager   # one-time, per machine
flutter pub get
flutter run
```

## Toolchain

- Flutter SDK: 3.41+
- iOS deployment target: 13.0
- Android: minSdk 21, target/compileSdk 34
- iOS dependencies via Swift Package Manager (CocoaPods fallback only)
